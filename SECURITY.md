# Security and privacy

Life Journal is designed for private, local-first personal records.

- Never publish a real journal vault without reviewing every generated page and asset.
- Keep service credentials in environment variables, never in Markdown or committed YAML.
- The public demo must be created from fictional data rather than redacted personal records.
- Exact coordinates, health information, relationships, and financial details should be treated as sensitive data.

Please report security issues privately to the repository maintainer rather than opening a public issue containing user data.
